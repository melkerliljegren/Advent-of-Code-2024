# Advent of Code 🎄

My solutions for [Advent of Code](https://adventofcode.com).
The goal is to practice problem solving, algorithmic thinking, and clean, efficient Python, while getting more comfortable with Git and GitHub.

## Structure

Solutions are organized by year, then by day:

2024/
day01/
input.txt
part1.py
part2.py
README.md
day02/
...

2023/
day01/
...

- `input.txt` contains the puzzle input.
- `part1.py` and `part2.py` contain my solutions for the day.
- `README.md` contains the puzzle of the day.
